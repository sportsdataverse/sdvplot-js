# sporty oracle fixtures

R truth captured from sportyR's built ggplot layers (every `GeomPolygon` layer in draw order as `layer_NNN.csv`, every `ggfittext` `GeomFitText` layer as `text_NNN.csv` — box centre `x, y`, `label`, `angle`, on its own counter — plus `coord_fixed` limits per display range).

- sportyR: 2.2.3 (git 29487c1, `/mnt/sdv_repos/sportyR`)
- R: 4.6.1 (2026-06-24)
- Generated: 2026-10-05 (football: 2026-10-06)
- Command: `Rscript tools/oracle/sporty.R basketball hockey football soccer` (repo root; `pnpm oracle:sporty` plus sport arguments)
- Re-verified: 2026-10-06 (every CSV byte-identical)

The fixtures were generated by the installed CRAN sportyR 2.2.3 build (packaged 2025-07-28), whose `surface_dimensions` was verified `all.equal` to the vendored `packages/sporty/data/surface-dimensions.json` at sha256 `1984f2cb8b89c318c38ae56c184442c89edcbf3597b2494080387dac2ff29fbb` (vendored from sportyR git 29487c1, DESCRIPTION 2.2.3). The oracle stops before writing anything if that check fails, and records the sha in `VERSION`; `packages/sporty/test/fixtures-version.test.ts` fails CI when the vendored JSON, its sportyR version or its checkout no longer match `VERSION`.

Never hand-edit; a mismatch is a TS bug. Consumed by `packages/sporty/test/parity.test.ts`.
