# sporty oracle fixtures

R truth captured from sportyR's built ggplot layers (every `GeomPolygon` layer in draw order as `layer_NNN.csv`, every `ggfittext` `GeomFitText` layer as `text_NNN.csv` — box centre `x, y`, `label`, `angle`, on its own counter — plus `coord_fixed` limits per display range).

- sportyR: 2.4.0 (git b97443a, sportyR main; it carries sportyR PR #68, merged as fb7ffe5)
- R: 4.6.1 (2026-06-24)
- Generated: 2026-10-24, every sport
- Command: `pnpm oracle:sporty basketball hockey football soccer baseball tennis volleyball curling lacrosse softball` (repo root), with `R_LIBS` pointing at a private library holding that sportyR (`R CMD INSTALL --library=<lib> <sportyR checkout>`) and `SPORTYR_REPO` at the checkout

The fixtures were generated by that locally installed sportyR 2.4.0 build, whose `surface_dimensions` was verified `all.equal` to the vendored `packages/sporty/data/surface-dimensions.json` at sha256 `2ff8561193860a8e384c1bc6144ce541c7e8c47ea70b3a85d9ce7dabbc6ca8b6` (vendored from sportyR git b97443a, DESCRIPTION 2.4.0). Against the 2.2.3 fixtures, soccer, tennis, baseball, curling and volleyball are byte-identical; basketball and hockey differ only in the last digits of some values (|Δ| ≤ 1.1e-13, far inside the 5e-10 parity tolerance: the local build versus the CRAN binary); lacrosse and football carry the sportyR #60-#67 and #69-#72 fixes (`field_bordered` outlines on NCAA, NFHS and NFL; the NCAA coaching line; the NFL bench corner). A 0-row polygon layer (the goal fan of a fan-less lacrosse league) draws nothing and gets no fixture. For one league per sport (basketball nba, hockey nhl, football ncaa, soccer epl, baseball mlb, tennis atp, volleyball fivb, curling wcf, lacrosse ncaaw, softball ncaa) the league folder also holds `units_<u>/` (the surface drawn in each other unit of m, ft and in: polygons, labels and `bbox_full.csv`) and `trans_10_-5/` (x_trans = 10, y_trans = -5), which check sportyR #74 and #76. The oracle stops before writing anything if that check fails, and records the sha in `VERSION`; `packages/sporty/test/fixtures-version.test.ts` fails CI when the vendored JSON, its sportyR version or its checkout no longer match `VERSION`.

Never hand-edit; a mismatch is a TS bug. Consumed by `packages/sporty/test/parity.test.ts`.
