# sporty oracle fixtures

R truth captured from sportyR's built ggplot layers (every `GeomPolygon` layer in draw order as `layer_NNN.csv`, every `ggfittext` `GeomFitText` layer as `text_NNN.csv` — box centre `x, y`, `label`, `angle`, on its own counter — plus `coord_fixed` limits per display range).

- sportyR: 2.4.5 (git e021040, sportyR main; the 2.4.5 CRAN release)
- R: 4.6.1 (2026-06-24)
- Generated: 2026-10-30, every sport
- Command: `pnpm oracle:sporty basketball hockey football soccer baseball tennis volleyball curling lacrosse softball` (repo root), with `R_LIBS` pointing at a private library holding that sportyR (`R CMD INSTALL --library=<lib> <sportyR checkout>`) and `SPORTYR_REPO` at the checkout

The fixtures were generated by that locally installed sportyR 2.4.5 build, whose `surface_dimensions` was verified `all.equal` to the vendored `packages/sporty/data/surface-dimensions.json` at sha256 `2ff8561193860a8e384c1bc6144ce541c7e8c47ea70b3a85d9ce7dabbc6ca8b6` (vendored from sportyR git e021040, DESCRIPTION 2.4.5; the file is byte-identical to the 2.4.0 one). Against the 2.4.0 fixtures, every arc moves in its last digits (sportyR 2.4.1 draws circles with `cospi()`/`sinpi()`); sportyR 2.4.1 leaves out a feature with no area and no visible outline, so zero-thickness lines lose their layers (basketball, football, lacrosse); and the hockey and lacrosse rings follow sportyR 2.4.1-2.4.5 (#79/#85, #89, #90, #92, #94). A 0-row polygon layer (the goal fan of a fan-less lacrosse league) draws nothing and gets no fixture. For one league per sport (basketball nba, hockey nhl, football ncaa, soccer epl, baseball mlb, tennis atp, volleyball fivb, curling wcf, lacrosse ncaaw, softball ncaa) the league folder also holds `units_<u>/` (the surface drawn in each other unit of m, ft and in: polygons, labels and `bbox_full.csv`) and `trans_10_-5/` (x_trans = 10, y_trans = -5), which check sportyR #74 and #76. The oracle stops before writing anything if that check fails, and records the sha in `VERSION`; `packages/sporty/test/fixtures-version.test.ts` fails CI when the vendored JSON, its sportyR version or its checkout no longer match `VERSION`.

Never hand-edit; a mismatch is a TS bug. Consumed by `packages/sporty/test/parity.test.ts`.
