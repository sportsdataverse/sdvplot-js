reactablefmtr in-cell charts. Three new column kinds draw each cell as an inline `<svg role="img">` with no script: `sparkline` (`react_sparkline`) and `sparkbar` (`react_sparkbar`) read an array column (the new `SeriesKey<Row>`: one array of numbers per row, `null` or any non-finite entry a gap), and `gauge` (`gauge_chart`) reads a number. They take reactablefmtr 2.1.0's defaults and options (highlighted points or bars, `statline`, `bandline`, value labels, an area, `minValue`/`maxValue`, a gauge's colour ramp, ends and `numberFormat`), with sdvplot's sparkline line width and point size of 1.5. Each chart's `aria-label` and `<title>` summarise its values (min, max, last, and the statline and band when drawn); a gauge fills by the absolute value, as reactablefmtr, and says so for a negative. `team` + `league` (or `colorRef`) colour each row, a team colour checked for 3:1 contrast on the table background. The chart size options are `chartWidth` / `chartHeight`, since `width` is the column's CSS width. `build()` rejects a `minValue` not below `maxValue`, non-positive or non-finite sizes, opacities outside 0 to 1 and unknown point, statline or bandline names, each error naming the option. Sparkline and sparkbar columns are not sortable by default. `GT_ALIASES` maps `react_sparkline`, `react_sparkbar` and `gauge_chart`.
