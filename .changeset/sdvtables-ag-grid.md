New subpath `@sportsdataverse/sdvtables/aggrid` for AG Grid 36 (`ag-grid-community`, the MIT Community edition only; nothing uses or needs `ag-grid-enterprise`). `gridOptions(spec, rows, o)` returns AG Grid's `columnDefs`, `rowData`, `getRowId`, `getRowStyle` and `rowHeight` from an sdvtables spec, plus, given a base theme such as `themeQuartz`, the theme's colours, fonts, header style and stripes through AG Grid's Theming API (dark themes such as `midnight` included): each column's label, alignment and px width, sdvtables' number formats (`num`, `int`, `pct`, superscript `rank`, and a `scaleNote`'s divisor and label suffix), number columns (AG Grid's number filter once filtering is on), sdvtables' own sort with missing values last both ways (blank numbers are missing, never 0), unique row ids checked when built, logo, wordmark and headshot cells through cell renderer classes that work in plain JavaScript and in ag-grid-react (abbreviations, names or numeric ids), and `teamColorBg` / `teamColorBar` cells and whole team-coloured rows (`teamRows`) in sdvplot's team palette for the theme's background with black or white text by contrast, kept through AG Grid's alternate rows, hover and selection. A team or player with no image keeps its text and warns once; kinds drawn in HTML or SVG show their plain value, with one warning per kind. It imports AG Grid's types only and loads on a server; `ag-grid-community` >= 36.2.0 is an optional peer.
