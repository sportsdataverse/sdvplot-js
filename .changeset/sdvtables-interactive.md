Interactive tables and PNG export:

- `createTable(spec, rows, { pageSize, sort })`, a headless engine with no table-library dependency: sort (typed comparators, a column's own `compare`, missing values last both ways), per-column and global text filters, paging, `toggleColumn`, `setRows`, immutable snapshots and `subscribe`. Pure helpers `applyFilters`, `applySort`, `paginate`, `comparatorFor`, `withMissingLast`, `nextSortDir`, `findColumn`, `isMissing`, `NUMERIC_KINDS`. For linked figures: `rowKey` (spec and builder), `rowId`, `setExternalFilter` (takes sdvplot's `RowFilter`, so a selection store's brush applies as it is), `setSelection`/`getSelection`, `setHover`/`getHover`, and `select`/`hover` events.
- `renderHTML(table)` in `@sportsdataverse/sdvtables/html`: sort buttons with `aria-sort`, a search box, per-column filter boxes and a pager. `hydrate(el, table)` progressively enhances server-rendered markup, re-rendering only the table block and batching changes into the next animation frame. A keyboard grid (`role="grid"` with one roving tab stop; `j`/`k`/`h`/`l`/`s` and `/` hotkeys, arrows, Enter/Space row selection; `interactive: { hotkeys: false }` keeps only the arrows, Enter and Space) through `handleKeydown`/`keyAction` and the engine's `TableCursor`. `handleClick`, `handleInput`, `handleHover`, `rowIdAt`, `renderInteractive`, `renderParts`, `assemble`, `tableHTML`, `attrsText`, `sortAria`, `tableRenderOptions`, `renderToolbar`, `renderPager` and `pagerLabel` serve custom renderers. Colour scales and legends span all rows, so a value keeps its colour while the user pages, filters or sorts; `selectRows` takes a `source` argument for index selectors.
- Row hover: an interactive table underlines the row under the pointer, or the row a linked figure hovers (`sdvt-hover`, a text-coloured underline at 3:1 or better in every theme). Opt out with `tr.sdvt-hover>td.sdvt-cell{background-image:none}`.
- `@sportsdataverse/sdvtables/react`: `useTable` and `<SdvTable/>`, whose server-rendered markup equals `renderHTML(table, { fonts: false })` and which is safe under React StrictMode; `fontsLinkFor(spec)` is the fonts `<link>` for the page head (`react` >= 18, an optional peer).
- `@sportsdataverse/sdvtables/export` (Node): `tableToPNG`, `htmlToPNG`, `socialCrop`, `batchToPNG`, `gridTables`, `stackTables`, `composePage` and `slug` (options `PNGOptions`, `SocialCropOptions`, `BatchOptions`), ports of sdvplotR's `gt_save_crop`, `gt_social_crop`, `gt_save_batch`, `gt_grid` and `gt_stack_tables` with the Python defaults (`playwright`, an optional peer).
