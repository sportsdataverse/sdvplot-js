Interactive tables and PNG export:

- `createTable(spec, rows, { pageSize, sort })`, a headless engine with no table-library dependency: sort (typed comparators, a column's own `compare`, missing values last both ways), per-column and global text filters, paging, `toggleColumn`, `setRows`, immutable snapshots and `subscribe`. Pure helpers `applyFilters`, `applySort`, `paginate`, `comparatorFor`, `withMissingLast`, `nextSortDir`, `findColumn`, `isMissing`, `NUMERIC_KINDS`. The link seam for linked figures: `rowKey` (spec and builder), `rowId`, `setExternalFilter`, `setSelection`/`getSelection`, `setHover`, and `select`/`hover` events.
- `renderHTML(table)` in `@sportsdataverse/sdvtables/html`: sort buttons with `aria-sort`, a search box, per-column filter boxes and a pager. `hydrate(el, table)` progressive enhancement re-renders only the table block. A keyboard grid (`j`/`k`/`h`/`l`/`s` and `/` hotkeys, arrows, Enter/Space row selection; `role="grid"` with one roving tab stop; `interactive: { hotkeys: false }` keeps only the arrows, Enter and Space), through `handleKeydown`/`keyAction` and the engine's `TableCursor` (`state.cursor`, `setCursor`). The handlers `handleClick`, `handleInput`, `handleHover` and `rowIdAt` are shared by `hydrate` and React; `renderInteractive`, `renderParts`, `assemble`, `tableHTML`, `attrsText`, `sortAria`, `tableRenderOptions`, `renderToolbar`, `renderPager` and `pagerLabel` serve custom renderers. In an interactive table colour scales and legends span all rows, so a value keeps its colour while the user pages, filters or sorts, and index row selectors count in the source rows (`selectRows` gains a `source` argument).
- `@sportsdataverse/sdvtables/react`: `useTable` and `<SdvTable/>`, whose server-rendered markup equals `renderHTML(table, { fonts: false })`; `fontsLinkFor(spec)` is the fonts `<link>` for the page head (`react` >= 18, an optional peer).
- `@sportsdataverse/sdvtables/export` (Node): `tableToPNG`, `htmlToPNG`, `socialCrop`, `batchToPNG`, `gridTables`, `stackTables`, `composePage` and `slug` (options `PNGOptions`, `SocialCropOptions`, `BatchOptions`), ports of sdvplotR's `gt_save_crop`, `gt_social_crop`, `gt_save_batch`, `gt_grid` and `gt_stack_tables` with the Python defaults (`playwright`, an optional peer).
- Static markup: an apostrophe is escaped as `&#x27;` (React's form), and every theme draws the subtitle on its own line (tufte and booktabs ran it into the title).
