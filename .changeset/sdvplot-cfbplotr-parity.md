The cfbplotR-era helpers of sdvplotR and Python sdvplot: `cleanNames` / `cleanNamesSync` (one display name per team value, cfbplotR's `clean_school_names()`), `aliases` (every name and id the index resolves), `teams(league, { division })` (FBS, FCS, DI, DII, DIII, the P4, P5 and G5 tiers, Conference), `teamFactor` / `teamFactorSync` (team values with their categories in abbreviation order), `altColors` on `palette` and `teamColors` (teams drawn in their other colour) and `addAthleteId` (ESPN athlete ids for college football player names, from cfbfastR-data's rosters). Each matches Python sdvplot on the same index.
