New subpath `@sportsdataverse/sdvtables/tanstack-table` for TanStack Table v9 (`@tanstack/table-core` 9, with its React, Svelte and other adapters), replacing the README's untested `@tanstack/react-table` 8 recipe. `tanstackTable(spec, rows, { features, render })` returns `options` for `useTable` (React) or `createTable` (Svelte), with your `tableFeatures` passed through, and `columnStyle`: one accessor column per spec column with the HTML table's label (a `scaleNote`'s suffix included) and number text (`num`, `int`, `pct`, ordinal `rank`, a `scaleNote`'s divisor and decimals; a blank number is missing, never 0), sdvtables' own sort through `sortFn` with missing values last both ways (`sortUndefined: "last"`), and row ids from the spec's `rowKey`, checked unique and not blank when built. Logo, wordmark, headshot and superscript-rank cells come to `render` as plain `CellPart` data for the caller's framework to draw (abbreviations, names or numeric team ids); a team or player with no image keeps its text and warns once; kinds drawn in HTML or SVG show their plain value, with one warning per kind. It imports table-core's types only and touches no DOM, so it loads on a server; `@tanstack/table-core` >= 9.3.1 is an optional peer.
