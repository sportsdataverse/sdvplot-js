New subpath `@sportsdataverse/sdvplot/tanstack` for TanStack Charts 1.x. `teamColorScale(league, teams, o)` returns the chart's `color` option (`{ domain, range }`, the team values kept as the data holds them) and `teamColorPalette` the colours alone; with `background` they keep 3:1 contrast on it (dark mode). TanStack Charts has no image mark, so `logoDots`, `wordmarkDots` and `headshotDots(rows, o)` return one `dot` mark's data and options per image, each dot filled with an SVG pattern of its image, `size` px tall and centred on each row's x/y fields; `withPatterns(renderChartSvg, ...dots)` is the chart's `renderSvg`, which writes those patterns into the chart's own SVG (server render and SVG export included). The dots keep TanStack's focus, tooltips and keyed updates. A team with no logo, or a gsis player id with no headshot, draws nothing and warns once (ESPN headshot URLs are built from the id unchecked, so an ESPN id with no photo leaves its dot unpainted, with no warning); SVG renderer only (the Canvas renderer leaves an unknown `url(#...)` fill unpainted). `drawnMarks(...dots)` reads back what the dots draw. It never imports TanStack Charts; `@tanstack/charts` >= 1.1.0 is an optional peer.
