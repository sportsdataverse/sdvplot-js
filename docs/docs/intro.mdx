sdvplot-js draws team logos, headshots, team colours and playing surfaces (courts, rinks, fields) for
[Observable Plot](https://observablehq.com/plot/) and D3. It is made of two packages:

- `@sportsdataverse/sdvplot` — logo and colour data per league, plus Plot, D3 and React helpers.
- `@sportsdataverse/sporty` — playing-surface geometry and the coordinate frames that move source data onto it.

Everything runs in the browser, in an Observable notebook, and in Node (pass `document` to `Plot.plot`).

Start with the examples for your league family: [basketball](examples/basketball.mdx),
[hockey](examples/hockey.mdx), [football](examples/football.mdx). The generated API reference covers every
public entry point of both packages.
