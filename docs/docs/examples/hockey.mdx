Hockey event data arrives on many canvases (HockeyTech's pixel grids, the NHL's feet from centre ice), and the rink
differs by league. Each figure on this page is drawn by the code under it, and the same code runs in CI on every pull
request; in Node, see [Node and SSR](../guides/node-ssr.mdx).

## Shot map: a rink in team colours, dots, logos

HockeyTech events on the 850 × 400 canvas move onto a 200 × 85 ft rink painted in Boston's colours.

<Live id="sdvplot/plot/nhl-shot-map" />

## HockeyTech canvases

HockeyTech leagues report events on one of two pixel canvases (850 × 400 or 600 × 300, origin top-left, y down);
`hockeytech-a` and `hockeytech-b` map both onto the rink.

<Live id="sporty/frames/hockeytech" />
