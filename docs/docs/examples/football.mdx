Football plays are reported against the yardline, so a play map needs the field and a frame that puts each yardline
in place; team colours go on the end zones. Each figure on this page is drawn by the code under it, and the same code
runs in CI on every pull request; in Node, see [Node and SSR](../guides/node-ssr.mdx).

## ESPN yardlines

ESPN plays carry a 0-100 yardline, measured from the home team's goal line, and no position across the field; the
`espn-football-0-100` frame centres the field so that midfield is `x = 0`, and passes a `y` through when a source has
one.
