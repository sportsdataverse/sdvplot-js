Two subpaths turn figures and tables into images in Node, with the defaults of sdvplotR's and the Python sdvplot's
`gt_save_crop`, `gt_social_crop`, `gt_save_batch`, `gt_grid` and `gt_stack_tables`. `@sportsdataverse/sdvplot/export`
draws an SVG figure with resvg and needs no browser. `@sportsdataverse/sdvtables/export` lays tables out in headless
Chromium through playwright. Both renderers are optional peers: a function whose peer is not installed throws
`OptionalDependencyError` naming the install command, and arguments are checked before anything starts.

## A figure as a PNG, without a browser

`socialCard` frames an SVG for a post the way `gt_social_crop` does: padded, then the short side widened to the ratio,
never cropped. `toPNG` draws it with `@resvg/resvg-js` (`pnpm add -D @resvg/resvg-js`), downloading each remote logo
once.

<Live id="sdvplot/export/social-card" />

The framing is plain arithmetic, shared with sdvtables' `socialCrop`: the figure's size (`svgSize`), the ratio
(`parseAspect`), the canvas (`canvasFor`) and where the figure sits on it (`parseGravity`, `offsetFor`).

<Live id="sdvplot/export/framing-math" />

`peerMissing` is how both subpaths tell a missing optional peer from one that is installed but broken.

## Tables as PNGs, in Chromium

Install the peer and its browser once:

```sh
pnpm add -D playwright
pnpm exec playwright install chromium
```

`tableToPNG` renders a table at zoom 2, trims it to its content and puts 50 px of background back around it.
`socialCrop` puts the trimmed table on a fixed-ratio canvas, `htmlToPNG` does the same for any HTML (a page of
tables, say), and `batchToPNG` writes one image per value of a group column, all as wide as the widest. This script
writes all four for the 2024 AFC standings:

<Snippet file="export/standings-png.ts" />

Its first image, `afc.png`:

![The 2024 AFC standings as a PNG: team, quarterback, wins, losses, points for and points against for eight teams, in the athletic theme](/img/sdvtables-export-afc.png)

These docs are built without a browser, so the image above is not drawn live: it is the script's own output,
regenerated by `pnpm --filter @sportsdataverse/examples render:export-png`. CI's render-tests job runs the
script on every push to main and every PR. That job is non-gating; the examples typecheck covers the script too.

An image past Chromium's canvas limit (65,535 px a side, 268,435,456 px in all, near 1,000 plain rows at zoom 2)
throws `SdvplotError` naming its size, and nothing is written. Put fewer rows in each image: a page at a time,
`batchToPNG` by a group, or `gridTables` side by side.

## Pages of tables, as HTML

`gridTables` (`gt_grid`) and `stackTables` (`gt_stack_tables`) return HTML: the tables, with a title, subtitle,
caption and source note around them. `htmlToPNG` turns that page into an image, as in the script above. One spec used
twice gets distinct ids, so each copy keeps its decorations.
